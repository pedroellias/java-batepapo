# Bate-Papo Java

Implementação de um bate-papo simples em Java para aprender a usar Sockets e Threads.

## Como rodar

Testado com Java versão 26.

1. Inicia o Servidor (deve ser aberto primeiro)
```bash
make Servidor
```
Com o servidor rodando, digite `help` para ver os comandos disponíveis.

2. Inicia o Cliente (em outro terminal, podem haver vários)
```bash
make Cliente
```
Digite `exit` no cliente para sair.
